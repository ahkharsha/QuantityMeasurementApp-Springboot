# Quantity Measurement App

A Java-based Spring Boot REST API for converting, comparing, and calculating physical quantities, designed using a clean Controller-Service-Repository architecture.

## Overview
This application handles mathematical operations and unit conversions across various physical quantities (Length, Volume, Weight, and Temperature). It features robust exception handling, persistent database history tracking, and interactive API documentation. 

## Tech Stack
* Java 21
* Spring Boot
* H2 Database / SQL
* Swagger / OpenAPI (Documentation)
* JUnit 5 & Mockito (Testing)

## How to Run
1. Switch to the `dev` branch to access the application source code.
2. Open the project in your IDE (Spring Tool Suite).
3. Run the `QuantityMeasurementApplication.java` main class as a Spring Boot App.
